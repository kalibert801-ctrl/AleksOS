1. Что такое AleksOS
AleksOS — прошивка для портативной игровой консоли на базе ESP32 с сенсорным экраном.
Консоль эмулирует игры для Nintendo Entertainment System (NES / Famicom).

Игры хранятся на карте памяти MicroSD в формате .nes. Карту нужно вставить перед включением.

4. Поиск, фильтры и сортировка

Поиск по названию
1. Нажать 🔍 в шапке (или кнопку ← в главном меню)
2. Откроется клавиатура — ввести часть названия игры
3. OK — показать результаты
4. ← BACK или кнопка B — отменить поиск

Пример: введите «mar» — найдёт «Mario Bros», «Marble Madness» и т.д.

Фильтр «Избранные»
Нажать ★ в левом углу шапки — список переключится в режим «только избранные игры».
Повторное нажатие — вернуть полный список.

7. Второй игрок — BLE геймпад (Android)
Второй игрок управляет через Android-приложение AleksOS Controller по Bluetooth LE.
Сопряжение через системные настройки телефона не требуется.

Что нужно:
• Консоль AleksOS с включённым Bluetooth (Settings → System → Bluetooth)
• Телефон на Android 6.0+ с приложением AleksOS Controller
• Включённый Bluetooth на телефоне

Как подключиться:
1. Войти в 2-player режим на консоли — она начнёт рекламироваться по BLE
2. Открыть приложение AleksOS Controller на телефоне
3. Нажать «Подключить»
4. Выбрать AleksOS из списка — соединение устанавливается автоматически
5. Иконка Bluetooth в верхней строке приложения станет жёлтой

Кнопки приложения:
┌──────────────────┬──────────────────┐
│ Кнопка           │ Кнопка NES       │
├──────────────────┼──────────────────┤
│ D-pad            │ Крестовина       │
│ A (зелёная)      │ A                │
│ B (красная)      │ B                │
│ SELECT           │ Select           │
│ START            │ Start            │
└──────────────────┴──────────────────┘

Отключить: нажать ✕ в верхней строке приложения.

Примечание: если устройство уже было сопряжено ранее — оно появится в списке
автоматически при следующем сканировании.

9. Скриншоты

Как сделать скриншот
1. Во время игры нажать HOME → Screenshot
2. Снимок сохранится на SD-карту в папку /Screenshots/
3. Первый снимок для каждой игры автоматически становится обложкой в главном меню
4. Последующие снимки нумеруются: Игра_001.raw, Игра_002.raw... — обложка не перезаписывается

Просмотр скриншотов
Скриншоты доступны через веб-интерфейс:
1. Запустить Web Manager (Settings → System → SD Manager)
2. Открыть IP-адрес консоли в браузере
3. Перейти в папку Screenshots — все снимки отображаются с предпросмотром

10. Избранное

Добавить в избранное:
• Нажать ☆ справа в строке игры → станет ★ (золотая)
• Или: открыть информацию об игре (правая панель) → нажать A

Убрать из избранного:
• Нажать ★ → станет серой

Показать только избранные:
• Нажать ★ в левом углу шапки → список отфильтруется
• Повторное нажатие — вернуть все игры

Список избранных сохраняется в /game_stats.json на SD-карте.

11. Game Genie — читы
Game Genie позволяет вводить коды-читы для изменения поведения игры
(бесконечные жизни, неуязвимость и т.д.).

Как включить и ввести код
1. Settings → Controls → Game Genie — включить функцию
2. В том же разделе нажать на строку Game Genie для ввода кодов
3. Ввести код (6 или 8 символов: буквы A–Z и цифры)
4. Нажать OK для сохранения

Формат кодов
• 6 символов — без адреса сравнения: SXIOPO
• 8 символов — с адресом сравнения: AATOZE

Совет: коды для конкретных игр можно найти на gamegenie.ca или gamehacking.org.

Слоты кодов
Хранится до 8 кодов одновременно. Коды применяются при следующем запуске игры.

12. Сохранение и загрузка состояний
Save State — моментальное сохранение состояния игры (позиция, жизни, счёт).

Сохранить:
В меню паузы (HOME в игре) → Save State
Файл сохраняется как ИмяИгры.nes.ss0 на SD-карте.

Загрузить:
В меню паузы → Load State

⚠️ Загрузка заменяет текущий прогресс. Если файла нет — появится «No save found!».

Один слот на игру. При повторном Save State предыдущее сохранение перезаписывается.

14. Файловый менеджер
Открыть: кнопка ← в главном меню.

В файловом менеджере можно:
• Просматривать список ROM-файлов на SD-карте
• Переименовывать игры (название в меню)
• Удалять ROM-файлы с карты памяти

Переименование:
Выбрать игру → нажать STA или Rename → ввести новое название → OK

Удаление:
Выбрать игру → ⋮ → Delete → подтвердить: YES Delete

⚠️ Удаление ROM-файла необратимо. Файл удаляется с SD-карты.

16. WiFi, время и обновление прошивки

Подключение к WiFi
1. Settings → System → WiFi
2. Выбрать сеть из списка
3. Ввести пароль → OK
4. Иконка WiFi в подвале меню станет зелёной

Синхронизация времени и даты
После подключения к WiFi время и дата обновляются автоматически через NTP.
Часовой пояс определяется по IP — настраивать вручную не нужно.

Ручная настройка: нажать на часы в подвале меню или Settings → Display → Date & Time.

Обновление прошивки — через интернет (GitHub OTA)
1. Подключиться к WiFi
2. Settings → System → Check Update → выбрать WEB
3. Консоль проверит новую версию и скачает обновление
4. После скачивания — автоматическая перезагрузка

⚠️ Не выключайте консоль во время обновления прошивки!

Обновление прошивки — через SD-карту (SD OTA)
1. Поместить файл прошивки (.bin) в папку /update/ на SD-карте
2. Settings → System → Check Update → выбрать SD
3. Выбрать файл кнопками ↑/↓, нажать A для прошивки
4. Ввести пароль: 1234
5. Подтвердить: нажать A (Cancel = B)
6. Консоль прошьёт файл и перезагрузится

⚠️ Используйте только официальные файлы прошивки AleksOS!

17. Web Manager — управление файлами
Web Manager позволяет передавать файлы на SD-карту из браузера по WiFi.

Запуск
1. Settings → System → SD Manager
2. Если WiFi не подключён — консоль подключится автоматически
3. На экране появится IP-адрес: http://192.168.x.x
4. Открыть адрес в браузере на телефоне или ПК
5. Остановить: нажать B

Интерфейс — левая панель (папки):
┌──────────────────────┬────────────────────────────────────────┐
│ Папка                │ Содержимое                             │
├──────────────────────┼────────────────────────────────────────┤

Правая панель — содержимое выбранной папки:
• Upload — выбрать файл(ы) и загрузить на SD
• + New — создать подпапку
• ✕ — удалить файл или папку (с подтверждением)

Советы:
• Можно загружать несколько файлов одновременно
• Загруженные игры сразу появятся в меню после выхода из Web Manager
• Для OTA: загрузить .bin в папку Firmware, затем System → Check Update → SD

18. Решение проблем

Игры не отображаются в меню
• Убедитесь, что SD-карта вставлена до включения
• Файлы должны иметь расширение .nes
• Файлы должны находиться в папке /FomiCon/ на SD-карте
• Перезагрузите консоль

Нет звука
• Проверьте: HOME + ↑ в игре (громкость эмулятора)
• Settings → Audio → Volume и Emu Volume — убедитесь, что > 0
• Settings → Audio → Sound — должно быть включено

Игра зависла
• Нажмите HOME — откроется меню паузы → Exit to Menu
• Если не реагирует — удерживайте HOME несколько секунд

Обложки не показываются
• Сделайте скриншот в игре (HOME → Screenshot) — первый снимок = обложка автоматически

Консоль не подключается к WiFi
• Проверьте пароль (чувствителен к регистру)
• Убедитесь, что сеть использует 2.4 GHz (5 GHz не поддерживается)
• Попробуйте переподключиться

Время или дата показывают неправильно
• Подключитесь к WiFi — время и дата обновятся автоматически
• Без WiFi: нажать на часы в подвале меню → Display → Date & Time
