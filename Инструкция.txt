1. Что такое AleksOS
AleksOS — прошивка для портативной игровой консоли на базе ESP32 с сенсорным экраном. Консоль эмулирует игры для Nintendo Entertainment System (NES / Famicom).

Игры хранятся на карте памяти MicroSD в формате .nes. Карту нужно вставить перед включением.


2. Кнопки управления
Игровые кнопки
Кнопка	Назначение
↑ ↓ ← →	Крестовина — движение в меню и в игре
A	Действие / выбор
B	Отмена / назад
SEL	Select — в меню: выход в настройки
STA	Start — запуск выбранной игры
HOME	Системная кнопка — открыть/закрыть меню паузы в игре
Сенсорный экран
Консоль управляется касанием пальца. Большинство действий дублируются между кнопками и тачскрином. Для прокрутки списка можно провести пальцем вверх или вниз.

Шапка (верхняя строка)
Элемент	Где	Действие
★ (звезда)	Левый край	Включить/выключить фильтр «Только избранные»
🔍 (лупа)	Рядом со звездой	Открыть поиск по названию
NES GAMES	Центр	Название экрана
42	Правее центра	Количество игр в текущем списке
⋮ (три точки)	Правый край	Дополнительное меню (сортировка, галерея, удаление, настройки)
Список игр (левая часть)
▶ — маркер выбранной игры
☆ — не в избранном; нажать звезду, чтобы добавить
★ — в избранном; нажать звезду, чтобы убрать
Навигация:

Кнопки ↑ / ↓ или касание строки — выбрать игру
Провести пальцем вверх/вниз — быстрая прокрутка
▲ / ▼ стрелки у правого края — прокрутка на одну строку
Правая панель
Обложка — изображение из скриншота (если был сделан)
T: — общее время игры
S: — размер файла ROM
Нажать на правую панель — открыть подробную информацию об игре
Подвал (нижняя строка)
Элемент	Действие
▶ PLAY	Запустить выбранную игру
WiFi иконка	Зелёная = подключено; Красная = нет связи
🔋 батарея	Уровень заряда
Время/Дата	Текущее время и дата

4. Поиск, фильтры и сортировка
Поиск по названию
Нажать 🔍 в шапке (или кнопку ← в главном меню)
Откроется клавиатура — ввести часть названия игры
OK — показать результаты
← BACK (кнопка внизу клавиатуры) или кнопка B — отменить поиск
Пример: введите «mar» — найдёт «Mario Bros», «Marble Madness» и т.д.

Фильтр «Избранные»
Нажать ★ в левом углу шапки — список переключится в режим «только избранные игры». Повторное нажатие — вернуть полный список.

Сортировка
Нажать ⋮ → выбрать Sort:

Режим	Описание
Sort Default	Исходный порядок файлов на карте
Sort A→Z	По алфавиту (А до Я)
Sort Z→A	По алфавиту в обратном порядке
Sort Size	По размеру файла
Текущий режим показан в меню. Каждое нажатие переключает на следующий.


5. Запуск игры
Способы запуска:
Способ	Действие
Кнопка ▶ PLAY (подвал)	Запустить текущую выбранную игру
Кнопка STA	Запустить текущую выбранную игру
Двойное касание строки игры	Запустить
Кнопка A после выбора	Запустить
Перед запуском консоль загружает ROM с карты памяти. Загрузка занимает 1–3 секунды.


6. Управление в игре
Кнопки консоли соответствуют оригинальному геймпаду NES:

Кнопка консоли	Кнопка NES
A	A
B	B
STA	Start
SEL	Select
↑ ↓ ← →	Крестовина D-Pad
Совет: Раскладку кнопок можно изменить в разделе Settings → Controls → Button Remap.

Регулировка громкости в игре
Удержать HOME + нажать ↑ — громче
Удержать HOME + нажать ↓ — тише

Появится индикатор громкости на экране.


7. Внутриигровое меню (пауза)
Во время игры нажмите HOME — откроется меню паузы.

┌────────────────────────────────┐
│         || PAUSE ||            │
├────────────────────────────────┤
│         Continue               │
│         Save State             │
│         Load State             │
│         Screenshot             │
│         Exit to Menu           │
└────────────────────────────────┘
Пункт	Действие
Continue	Продолжить игру
Save State	Сохранить состояние игры (слот 0)
Load State	Загрузить сохранённое состояние
Screenshot	Сделать снимок экрана
Exit to Menu	Выйти в главное меню
Навигация:

↑ / ↓ — выбрать пункт
STA или SEL — подтвердить
B — закрыть меню (= Continue)
HOME ещё раз — закрыть меню
⚠️ Важно: HOME нужно отпустить прежде чем нажимать снова для закрытия меню.


8. Скриншоты и галерея
Как сделать скриншот
Во время игры нажать HOME → Screenshot
Снимок сохранится на SD-карту в папку /Screenshots/
Первый снимок для каждой игры автоматически устанавливается как обложка (картинка в правой панели меню)
Последующие снимки нумеруются: Игра_001.raw, Игра_002.raw... — обложка не перезаписывается
Галерея скриншотов
Открыть: ⋮ → Gallery

Уровень 1 — Список игр:

Показаны все игры, у которых есть скриншоты
Правая панель — текущая обложка выбранной игры
A или двойное касание — войти в папку игры
B — выйти из галереи
Уровень 2 — Скриншоты игры:

Список "Shot 001", "Shot 002"...
Правая панель — предпросмотр выбранного снимка
A или касание правой панели — открыть на весь экран
B — назад к списку игр
Уровень 3 — Полный экран:

Снимок во весь экран
STA или касание левой части нижней полосы — установить как обложку игры
B или касание правой части нижней полосы — назад
Появится вопрос: YES — Set cover / NO — Cancel

9. Избранное
Добавить в избранное:

Нажать на ☆ справа в строке игры в меню → станет ★ (золотая)
Или: открыть информацию об игре (правая панель) → нажать A
Убрать из избранного:

Нажать на ★ → станет серой
Показать только избранные:

Нажать ★ в левом углу шапки → список отфильтруется
Повторное нажатие — вернуть все игры
Список избранных сохраняется в файл /game_stats.json на SD-карте.


10. Game Genie — читы
Game Genie позволяет вводить коды-читы для изменения поведения игры (бесконечные жизни, неуязвимость и т.д.).

Как включить и ввести код
Settings → System → Game Genie — включить функцию
В главном меню нажать кнопку ← → открыть файловый менеджер → выбрать игру → нажать Game Genie
или: коды вводятся через пункт Game Genie в настройках
Ввести код (6 или 8 символов: буквы A–Z и цифры)
Нажать OK для сохранения
Формат кодов
6 символов — без адреса сравнения: SXIOPO
8 символов — с адресом сравнения: AATOZE
Совет: Коды для конкретных игр можно найти на сайтах gamegenie.ca или gamehacking.org. Введите название игры и Game Genie NES.

Слоты кодов
Хранится до 8 кодов одновременно. Каждый слот можно включить или выключить независимо.



11. Сохранение и загрузка состояний
Save State — моментальное сохранение состояния игры (всё: позиция, жизни, счёт).

Сохранить
В меню паузы (HOME в игре) → Save State

Файл сохраняется как ИмяИгры.nes.ss0 на SD-карте.

Загрузить
В меню паузы → Load State

⚠️ Внимание: Загрузка состояния заменяет текущий прогресс. Если файла нет — появится сообщение «No save found!».

Один слот
Система использует один слот на игру (слот 0). При повторном Save State предыдущее сохранение перезаписывается.

Нажать на правую панель в главном меню или кнопку →.

│               Played:  1ч 23м          │

Поле	Описание

Path	Путь к файлу на SD-карте
Нажать ★ Favourite или кнопку A — добавить/убрать из избранных
Нажать OK или кнопку B — закрыть


13. Файловый менеджер
Открыть: кнопка ← в главном меню.

В файловом менеджере можно:

Просматривать список ROM-файлов на SD-карте
Переименовывать игры (название в меню)
Удалять ROM-файлы с карты памяти
Переименование
Выбрать игру → нажать STA или Rename
Откроется клавиатура
Ввести новое название → OK
Удаление
Выбрать игру → нажать кнопку удаления (⋮ → Delete)
Подтвердить: YES Delete
⚠️ Удаление ROM-файла необратимо. Файл удаляется с SD-карты.



14. Настройки
Открыть: кнопка SEL в главном меню.

Настройки разделены на категории:

Display (Дисплей)
Параметр	Описание
Scale Mode	Режим масштабирования картинки (1:1, растяжение, пропорционально)
Brightness	Яркость дисплея

Audio (Звук)
Параметр	Описание
Volume	Громкость консоли (0–100%) — кнопки, звуки меню, музыка
Emu Volume	Громкость эмулятора (0–100%) — звук NES во время игры
Sound	Включить/выключить звук полностью

Примечание: громкость эмулятора также регулируется прямо в игре — HOME + ↑/↓.

Appearance (Внешний вид)
Параметр	Описание
Theme	Тема оформления меню
Доступные темы:

Dark — тёмная тема (по умолчанию)
Light — светлая тема
Green — зелёная ретро-тема
Amber — янтарная ретро-тема
Win98 — стиль Windows 98
Android — стиль Material Dark
iOS — стиль iOS
GameBoy — стиль Game Boy DMG
System (Система)
Параметр	Описание
Auto Scroll	Автоматическая прокрутка при удержании кнопки
Game Genie	Включить поддержку кодов Game Genie
Watchdog	Перезагрузка при зависании (рекомендуется включить)
WiFi	Настройка WiFi-соединения
Time/Date	Синхронизация времени через интернет (NTP)
Firmware	Текущая версия прошивки
Controls (Управление)
Параметр	Описание
Button Remap	Переназначение кнопок геймпада
Info (О системе)
Версия прошивки, IP-адрес, MAC-адрес, свободное место на SD-карте.



15. WiFi и обновление прошивки
Подключение к WiFi
Settings → System → WiFi
Выбрать сеть из списка
Ввести пароль на клавиатуре → OK
Иконка WiFi в подвале меню станет зелёной
Синхронизация времени
После подключения к WiFi: Settings → System → Sync Time — время и дата обновятся автоматически.

Обновление прошивки — через интернет (GitHub OTA)
Подключиться к WiFi
Settings → System → Firmware Update → выбрать WEB
Консоль проверит наличие новой версии и скачает обновление
После скачивания — автоматическая перезагрузка
⚠️ Не выключайте консоль во время обновления прошивки!

Обновление прошивки — через SD-карту (SD OTA)
Поместить файл прошивки (.bin) в папку /update/ на SD-карте
Settings → System → Firmware Update → выбрать SD
Ввести пароль: 1234
Выбрать файл кнопками ↑/↓, нажать A для прошивки
Консоль прошьёт файл и автоматически перезагрузится
⚠️ Используйте только официальные файлы прошивки AleksOS!


16. Web Manager — управление файлами
Web Manager позволяет передавать файлы на SD-карту прямо из браузера по WiFi — без извлечения карты.

Запуск
Settings → System → Web Manager
Если WiFi не подключён — консоль подключится автоматически
На экране появится IP-адрес: http://192.168.x.x
Откройте этот адрес в браузере на телефоне или ПК
Экран консоли остаётся включённым, пока сервер работает
Остановить: нажать Reset (кнопка B)

Интерфейс
Левая панель — папки:
Папка	Содержимое
ROMs (/FomiCon)	Игры (.nes)
Music (/Music)	Музыка (.mp3, .wav)
Sounds (/sounds)	Звуки интерфейса (.wav)
Cover art (/covers)	Обложки игр (.raw, .jpg, .png)
Firmware (/update)	Файлы прошивки (.bin)

Правая панель — содержимое выбранной папки:
Upload — выбрать файл(ы) и загрузить на SD
+ New — создать подпапку
✕ — удалить файл или папку (с подтверждением)

Советы
Можно загружать несколько файлов одновременно
Загруженные игры сразу появятся в меню после выхода из Web Manager
Для передачи прошивки загрузите .bin в папку Firmware и затем используйте SD OTA


17. Решение проблем
Игры не отображаются в меню
Убедитесь, что SD-карта вставлена до включения консоли
Файлы должны иметь расширение .nes
Файлы должны находиться в папке /FomiCon/ на SD-карте
Перезагрузите консоль
Нет звука
Проверьте громкость: HOME + ↑ в игре
Settings → Audio → Volume и Emu Volume — убедитесь, что громкость > 0
Settings → Audio → Sound — должно быть включено
Игра зависла
Нажмите HOME — откроется меню паузы → Exit to Menu
Если не реагирует — удерживайте HOME несколько секунд
Обложки не показываются
Сделайте скриншот в игре (HOME → Screenshot) — первый снимок автоматически станет обложкой
Или зайдите в Галерею и установите нужный снимок как обложку
Консоль не подключается к WiFi
Проверьте правильность пароля (пароль чувствителен к регистру)
Убедитесь, что сеть использует 2.4 GHz (5 GHz не поддерживается)
Попробуйте переподключиться
Время показывает неправильно
Подключитесь к WiFi и выполните Settings → System → Sync Time
Убедитесь, что в настройках выбран правильный часовой пояс
