# AleksOS BETA — NES консоль на базе ESP32

**AleksOS** — портативная игровая консоль на базе **ESP32-2432S028** («Cheap Yellow Display»).  
Использует ядро NES-эмулятора **Nofrendo** с полностью переработанным OSD-слоем под возможности ESP32.

---

## ⚠️ Важно: проект заточен под конкретное железо

Проект разработан специально под мою модифицированную плату.  
Работа на других платах, конфигурациях и ревизиях **не проверялась** и **не гарантируется**.

---

## Железо

| Компонент | Описание |
|-----------|---------|
| МК | ESP32 @ 240 МГц, 4 МБ Flash, 4 МБ PSRAM |
| Дисплей | ST7789 320×240 IPS, SPI DMA 80 МГц (LovyanGFX) |
| Звук | I2S внутренний ЦАП GPIO26, 44100 Гц, 4× передискретизация @ 176400 Гц, усилитель SC8002B |
| Хранилище | MicroSD карта (SPI) |
| Контроллер | Raspberry Pi Pico через UART2 (GPIO22/27) |
| Вибро | Виброматор подключён к Pico (GP10) |
| Подсветка | Авто-яркость через фоторезистор (GPIO34) |
| Тачскрин | XPT2046 резистивный |

## Возможности

### Эмулятор
- NES эмуляция 50+ FPS
- Поддержка большинства популярных mappers (NROM, MMC1, UNROM, CNROM, MMC3 и др.)
- Исправленный IRQ в MMC3 
- Браузер ROM — сканирует SD карту, навигация кнопками и тачем
- Обложки игр (файлы `.raw` в `/covers/`)
- Скриншоты на SD карту

### Управление
- Полный контроллер — A, B, Select, Start, Home, крестовина
- Выход из игры — зажать **HOME** 0.2 секунды
- Переназначение кнопок (ремаппинг)

### Звук
- DSP-цепочка: DC-блокер → TPDF-дизеринг → soft-knee лимитер → 4× передискретизация с линейной интерполяцией
- APU-фильтр, соответствующий реальному железу NES (~13.4 кГц при 44100 Гц)
- Кольцевой буфер в PSRAM (16 КБ), запас ~83 мс — исключает заикания
- WAV звуки интерфейса с SD карты

### Веб-интерфейс (по WiFi)
- **Файловый менеджер** — загрузка, удаление, переименование файлов и папок
- **Аудиоплеер** — воспроизведение MP3/WAV прямо в браузере без скачивания
- **Просмотр изображений** — JPG, PNG, BMP; скриншоты `.raw` декодируются через Canvas
- **Веб-консоль** — Serial-монитор в браузере (`/console`), работает в фоне
- **Удалённый экран** (`/remote`) — live-трансляция экрана + виртуальный геймпад

### Интерфейс
- Несколько тем оформления
- Авто-яркость по датчику освещённости
- Вибро-отклик в меню

## Модификация PSRAM

Плата модифицирована — добавлена внешняя микросхема PSRAM **APS6404L-3SQR-SN** (8 МБ QSPI).  
Используются выводы GPIO16/17, которые на оригинальной плате заняты RGB-светодиодом — светодиод удалён.

Автор идеи: [hexeguitar](https://github.com/hexeguitar/ESP32_TFT_PIO/blob/main/README.md)

<img alt="cyd_PSRAM_mod" src="https://github.com/user-attachments/assets/13a14e45-822b-409a-b7bd-12c2a5f268f4"/>

**Подходящие микросхемы:**
- `APS6404L-3SQR-SN` — 8 МБ (рекомендуется)
- `APS1604M-3SQR-SN` — 2 МБ (минимум)

> ⚠️ **Только версия `3SQR`** — модели без `3` рассчитаны на 1.8V. На CYD 3.3V — чип сгорит.

### ⚠️ Порядок установки PSRAM

При старте на линиях RGB-светодиода подаётся напряжение. Если припаять PSRAM **до** прошивки — чип сгорит.

**Правильный порядок:**
1. Прошить ESP32
2. Припаять APS6404L-3SQR-SN
3. Включить питание

## Контроллер кнопок (Raspberry Pi Pico)

На ESP32-2432S028 практически нет свободных GPIO, поэтому используется **Raspberry Pi Pico** как контроллер кнопок по UART.

**Подключение:**

| ESP32 | Pico | Назначение |
|-------|------|------------|
| IO22  | GP0 (TX) | Данные кнопок → ESP32 |
| IO27  | GP1 (RX) | Команды ESP32 → Pico |
| GND   | GND | Общая земля |
| 3.3V  | 3V3 | Питание Pico |

**Протокол:**
- Pico → ESP32: `[0xAA] [0x42] [кнопки] [~кнопки]`
- ESP32 → Pico: `[0xAA] [cmd] [data] [cmd ^ data]`
- Биты кнопок: `A=0x01 B=0x02 Sel=0x04 Sta=0x08 ↑=0x10 ↓=0x20 ←=0x40 →=0x80`

<img alt="pico connection" src="https://github.com/user-attachments/assets/a8ed13d6-e5b9-4065-87f8-9d7238d9c8a2"/>

### Прошивка Raspberry Pi Pico

Исходники находятся в папке `pico_controller/`. Прошивается через **Arduino IDE**.

> ⚠️ **Перед прошивкой Pico — отключить все провода от ESP32 (GP0, GP1, 3V3, GND).**  
> При подключении USB к Pico она начинает питать ESP32 через 3.3V — это перегружает стабилизатор Pico.

Порядок:
1. Отключить Pico от ESP32
2. Подключить Pico к ПК по USB
3. Открыть `pico_controller/` в Arduino IDE, выбрать плату "Raspberry Pi Pico"
4. Загрузить прошивку
5. Подключить Pico обратно к ESP32

> При прошивке **ESP32** отключать Pico не нужно.

## Сборка и прошивка

```bash
# Установить PlatformIO
pip install platformio

# Клонировать и собрать
git clone https://github.com/kalibert801-ctrl/AleksOS.git
cd AleksOS
pio run

# Прошивка (зажать BOOT, затем:)
pio run --target upload
```

Готовый бинарник: `releases/firmware.bin` — прошивается через esptool или `/update` в веб-менеджере.
